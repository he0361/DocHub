# 制度条款比对

当用户要求对比两份制度文档（如两份管理办法、新旧版本制度、不同部门规范）时，请按以下流程执行：

1. **定位文档**：先明确用户想对比的是哪两份文档。如果用户只提到一份，主动询问另一份的名称或编号。
2. **按条款结构对齐**：把两份文档按"章节 → 条款"结构对齐，找出：
   - 仅存在于其中一份的条款（新增 / 删除）
   - 两份都存在但内容不一致的条款（修改）
   - 表述不同但含义一致的条款（表述差异）
3. **输出结构化对比表**：优先给出 Markdown 表格，列包含「对比维度 / 文档A / 文档B / 差异说明」。
4. **给出影响提示**：对关键差异给出业务影响或注意事项，例如"若按新制度执行，XX 场景的审批层级将提升"。
5. **引用来源**：标注差异条款在各自文档中的章节位置，便于用户回溯核验。

注意：只依据文档实际内容做对比，不要臆造不存在的条款差异。

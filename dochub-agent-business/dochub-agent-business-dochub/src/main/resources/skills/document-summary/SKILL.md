# 文档摘要

当用户要求对文档或内容做摘要时，请按以下规范执行：

1. **明确对象与粒度**：先确认是对整份文档、某个章节，还是指定段落做摘要；不确定时按"整份文档"处理。
2. **结构化输出**：摘要采用"一句话总述 + 分层要点"结构：
   - **总述**：用一两句话概括文档核心主题与定位。
   - **要点**：按章节或主题分点，保留关键数据、结论与行动项，丢弃冗余铺垫。
3. **忠实原文**：摘要必须忠于原文，不添加原文没有的信息；关键数字、专有名词、结论保留原表述。
4. **长度适配**：
   - 简短摘要（<200 字）：只保留最重要的 3~5 个要点。
   - 完整摘要：按章节覆盖，每章 1~3 个要点。
5. **可交付**：输出 Markdown 格式；如用户需要，可进一步给出"一句话版本 / 完整版本 / 行动项清单"。

# 内部通讯起草

当用户要起草企业内部通讯时，按以下规范执行：

## 确认类型与受众
先明确通讯类型与受众（管理层 / 全员 / 项目组），不同类型结构与语气不同：
- **3P 更新**（进展 Progress / 计划 Plans / 问题 Problems）：每项 2~4 条，简洁量化。
- **状态/项目周报**：本周完成 → 当前进展 → 问题与风险 → 下周计划。
- **领导汇报**：结论先行 → 关键数据 → 风险与所需支持。
- **公司简报/新闻**：主题 → 要点 → 影响 → 下一步。
- **FAQ 回答**：问题先行 → 直接答案 → 补充细节。
- **事件报告**：事件概述 → 影响范围 → 根因 → 处置措施 → 后续预防。

## 风格要求
- 正式、简洁、面向受众：管理层看结论与风险，执行层看行动项。
- 关键数字、日期、状态明确；不堆砌修饰语。
- 通篇语气一致，专有名词统一。

## 可交付
- 输出 Markdown 正文；如需可进一步给"一句话版本"（领导快速浏览）或"邮件版本"（正式发送）。

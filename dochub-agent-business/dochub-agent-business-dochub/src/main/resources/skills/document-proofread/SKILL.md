# 文档校对润色

当用户要求校对/润色一段文档时，请按以下流程执行：

1. **先纠错、后润色**：先处理硬性问题（错别字、语法错误、病句、标点误用），再优化表达与格式。
2. **硬性校对清单**：
   - 错别字与用词不当（尤其是同音异形字）。
   - 语法错误、成分残缺、搭配不当、句式杂糅。
   - 标点误用、全半角混用、数字/单位不统一。
   - 专有名词、术语前后不一致。
3. **一致性检查**：人名/机构名/术语/编号/格式（标题层级、列表符号、日期格式）全文统一。
4. **润色原则**：
   - 保持原文语义与风格，不擅自改动事实与数据。
   - 压缩冗余、消解长句、提升可读性；不为了"高级"而堆砌辞藻。
   - 面向企业场景，保持正式、简洁、可执行。
5. **输出形式**：先给"校对结果清单"（问题位置 | 原文 | 修改后 | 原因），再给润色后的全文（Markdown）。如需可直接替换。

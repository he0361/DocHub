# 企业文档起草

当用户要求起草一份企业正式文档时，请按以下规范执行：

1. **确认要素**：在动笔前确认文档类型、目标读者、适用范围和关键要求；信息不足时用一句话向用户确认，不要臆测。
2. **搭建骨架**：先给出文档大纲（标题层级清晰），用户确认后再展开正文，或直接给出结构完整的成稿。
3. **遵循规范**：
   - 制度类：包含总则、适用范围、职责分工、执行流程、违规处理、附则。
   - 报告类：背景、现状分析、问题与原因、改进建议、下一步计划。
   - 周报类：本周完成、本周进展、问题风险、下周计划，简洁量化。
4. **语言风格**：正式、简洁、可执行；面向企业内部场景，避免口语化。
5. **可交付**：输出 Markdown 格式，便于用户导出为 .md 或 .docx；如需要可直接转交模板中心生成。

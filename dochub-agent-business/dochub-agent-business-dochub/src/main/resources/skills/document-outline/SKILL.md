# 文档大纲

当用户需要规划一份文档的大纲时，请按以下规范执行：

1. **确认要素**：动笔前确认文档类型（制度/报告/方案/周报/论文等）、目标读者、篇幅要求与关键内容；信息不足时先确认。
2. **层级清晰**：大纲使用标准 Markdown 标题层级（# 一级 / ## 二级 / ### 三级），同级标题风格统一。
3. **结构规范**：按文档类型给出合理骨架：
   - 制度类：总则 → 适用范围 → 职责分工 → 管理流程 → 违规处理 → 附则。
   - 报告类：背景 → 现状分析 → 问题与原因 → 对策建议 → 下一步计划。
   - 方案类：目标与范围 → 总体思路 → 详细设计 → 实施计划 → 风险与保障。
   - 通用类：引言 → 主体（按主题拆分）→ 结论。
4. **可执行性**：每个标题下用一句话说明该节要写什么，让大纲可直接指导正文生成。
5. **可交付**：输出 Markdown 大纲；如用户需要，可同时给"详细版"（带要点注释）与"精简版"（纯标题）。

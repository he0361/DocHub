# 文档对比

当用户要求对比多份文档时，请按以下流程执行：

1. **确认对比对象**：明确要对比哪几份文档、对比的维度（整体结构 / 具体条款 / 数据指标 / 写法风格）。信息不足时先用一句话确认。
2. **先各自提炼**：先分别梳理每份文档的核心内容、章节结构与关键结论，再进入对比，避免遗漏。
3. **结构化对比输出**：
   - **对比矩阵**：用表格呈现"维度 | 文档A | 文档B | 差异说明"，覆盖结构、关键条款、数据、结论等维度。
   - **差异清单**：按"新增 / 删除 / 修改 / 一致"分类，列出实质性差异点，标注出自哪个章节。
   - **结论建议**：最后给出差异影响判断与选用建议（如哪份更完整、哪个条款更严格）。
4. **忠实原文**：对比内容必须基于文档原文，不得臆测；引用差异点时要能定位到来源章节。
5. **可交付**：输出 Markdown 格式，便于导出为 .md 或 .docx。
